# 4-Week Post Sequence Calendar

**Cadence:** 3 posts/week — Tue / Thu / Sat, ~8:30am ET.
**Rhythm each week:** 1 carousel (idea) · 1 text post (story/argument) · 1 short build-log or reflection.
Numbers like `Caption 1` map to `linkedin_caption_bank.md`. Carousels map to `/carousels`.

> Before Week 1: publish the **Featured Section** + **About insert** (`/profile`). Set the frame first.

## After the 4 weeks
- Repost the strongest performer as a "in case you missed it" with a fresh 1-line hook.
- Turn the campaign into 1 long-form **case study** (host `/html/case_study_page.html`) and link it in Featured.
- Keep a monthly "build log": each time the Market Brief regenerates, post one grounded insight from it.

## Metrics to glance at (weekly, not obsessively)
- Saves + meaningful comments (quality signal).
- Profile views + connection requests from PM / founder / AI-builder titles.
- Clicks to the live app (put it in comments and track anecdotally).
- Any inbound DM referencing the project = the campaign working.
