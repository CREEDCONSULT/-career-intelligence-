# Visual Motifs

The recurring visual vocabulary. Reuse these so every asset reads as one system — the same
world as the dashboard itself.

## 1. Grid overlay background
A faint square/technical grid on the deep background. Line color `#29384C` at ~8–12% opacity,
~48px cells. Signals "system / console / data product." Present on almost every slide, quiet.

## 2. Ghosted orbs / gradient glow
One large, soft, blurred radial glow (gold `rgba(213,181,110,0.16)` or blue) behind the content,
usually top-right or behind a hero line. Never more than one per slide. Adds depth without noise.

## 3. Thin horizontal dividers
2px gold line, ~120px wide, under the title. Or 1px full-width `#29384C` to separate zones.
The gold divider is a signature — use it consistently.

## 4. Dashboard cards with labels
Rounded (16px) dark cards with a mono eyebrow label and a value/body. The core building block.
3px left accent border encodes meaning (gold=key, blue=AI/data, green=verified, red=warning).

## 5. Flow arrows: data → AI → decision
Left-to-right (or top-down) blocks connected by thin gold arrows. The AI block is blue-accented;
the final decision/output block gets a green tick. This is the campaign's signature diagram.

## 6. Numbered stage markers
Small mono circles/squares (`01`, `02`, …) in gold, marking steps in a flow or layers in a stack.
Consistent size (~40px). Used in guardrail flow, layer stacks, application examples.

## 7. Product roadmap phases
A slim horizontal timeline of 6 nodes. Node 1 filled gold = "you are here (Phase 0)"; future nodes
outlined/muted. Connector line `#29384C`. Used for productization content.

## 8. System architecture blocks
Labeled rectangles stacked or arranged as a pipeline. Each block = a layer (Data / Analytics / AI /
UX / Evaluation / Product). Thin borders, mono labels, one accent per diagram.

## 9. Evaluation / trust scorecards
A horizontal strip or 2×2 of metric tiles: number (mono, cream) + label (mono, gold). Passing
metrics get a small green tick. Used to show the real eval numbers (80% / 0 / 0.94 / 5-of-5).

## 10. "Proof-of-work" badges
Small pill or seal, gold outline on dark, mono text: `PROOF-OF-WORK`, `● LIVE`, `GROUNDED`,
`VERIFIED`. Used sparingly as trust marks — cover slides, closers, scorecards.

## Guardrail-specific motifs
- **Shield + ✓ badge** for "no-invent / grounded" checkpoints.
- **Fork arrow** with two outcome chips (`REFUSE` red-muted / `SHOW DATA` blue) for refusal logic.
- **"number matched" link line** — a thin gold line connecting a figure in an answer card to a cell
  in a result-table tile.

## Texture & finish
- Subtle noise/grain over the background at ~2–3% is allowed (premium print feel). Keep it barely there.
- No drop shadows heavier than `0 8px 24px rgba(0,0,0,0.35)`. Depth comes from borders + glow, not shadow.
- Corners: 16px on cards, 9999px on pills, 8px on small chips.

## Hard bans (from the brief)
- No robots, androids, humanoid AI.
- No neon cyberpunk, no glitch, no matrix rain.
- No cartoon/startup mascots, no playful blobs.
- No stock-photo people, no handshakes, no "corporate team."
- No random circuit-board or brain-with-chips clichés.
- If it looks like generic AI stock art, it's wrong for this system.
