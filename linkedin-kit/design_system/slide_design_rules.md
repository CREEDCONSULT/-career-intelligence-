# Slide Design Rules

Practical rules for producing a clean, consistent carousel. If a slide breaks three of these, redo it.

## The 10 rules
1. **One idea per slide.** If you're explaining two things, make two slides.
2. **One accent leads.** Gold by default; blue when the slide is about AI/data. Never a rainbow.
3. **Title = 2–4 words per line.** Big, cream, tight tracking. If it wraps to 4 lines, cut words.
4. **Eyebrow always present.** Mono, gold, UPPERCASE, top-left (e.g. `GUARDRAILS · 03`). It orients the swipe.
5. **Numbers are heroes.** Any metric is the biggest non-title element, in mono.
6. **30–40% empty space.** This is executive, not a flyer. Crowding kills the premium feel.
7. **Consistent header zone.** Eyebrow + title sit in the same place on every slide of a deck.
8. **Left-align by default.** Center only single hero statements and closers.
9. **Every claim is real.** No invented metrics on slides. Use the verified numbers only.
10. **Cover and closer bookend.** Cover states the promise; closer states the takeaway + soft CTA + monogram.

## Per-slide checklist
- [ ] Eyebrow label present, gold, mono, uppercase.
- [ ] Title ≤ 4 words/line, cream, high contrast.
- [ ] Gold divider under title (or a deliberate reason it's absent).
- [ ] One leading accent; supporting accents only if meaningful (blue=AI, green=verified).
- [ ] Body ≤ ~42 chars/line, slate, 1.4 leading.
- [ ] Any number in mono; hero number sized up.
- [ ] Grid overlay quiet; at most one ghosted orb.
- [ ] Safe margins 88px; nothing critical near the edge.
- [ ] Footer/monogram on cover + closer (optional on interior slides).
- [ ] No banned imagery (robots, neon, stock people, cliché AI).

## Carousel-level consistency
- Fixed cover template + fixed closer template across all 5 decks.
- Same eyebrow format: `TOPIC · NN`.
- Same footer sign-off: monogram + "Mesomachukwu Mezie-Akabudu · creedConsult".
- Slide count 9–10; keep it swipe-able. LinkedIn shows up to ~10 well.

## Export specs
- **Size:** 1080×1350 (4:5). **Format:** PNG (or PDF for a single upload).
- **Color:** sRGB. **Text:** never below 20px. **File names:** `c0N_slide_MM.png`.
- Keep a 1-slide "hook variant" of each cover for A/B testing the first frame.

## Screenshot slides (real dashboard frames)
When using actual dashboard screenshots (Ask, Advisor, Resume Studio, Market Brief):
- Frame them in a dark card with a 1px `#29384C` border, 16px radius.
- Add a mono caption label above (e.g. `MODULE · ASK THE DATA`).
- Dim the screenshot ~6% and add the grid behind so it sits inside the system.
- Real frames > illustrations. Use them whenever the point is "this is real."
