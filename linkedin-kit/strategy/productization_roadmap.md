# Productization Roadmap

The honest framing: **today this is Phase 0 — a proof-of-work.** The value of the roadmap is that
it exists and is sequenced. It shows I designed the ramp before I needed it.

> A dashboard becomes a product when it has users, workflows, trust, and a business model.

---

## Phase 0 — Open proof-of-work · **shipped**
**Purpose:** showcase AI product strategy and systems thinking.
- Live app, public repo, 8 modules, real evaluation metrics, honest limitations.
- **Proof:** 97,227 postings · 80% text-to-SQL accuracy · 0 invented numbers · 0.94 brief faithfulness.
- **Business meaning:** credibility asset + top-of-funnel for everything below.

## Phase 1 — Gated beta
**Features:** login, user accounts, saved sessions, usage analytics.
- Turns anonymous traffic into known users and a feedback loop.
- **Unlocks:** retention data, first qualitative interviews, waitlist.
- **Metric that matters:** returning users / week.

## Phase 2 — Personal intelligence layer
**Features:** saved resumes, role watchlists, skill-gap plans, personalized market alerts.
- The product stops being a lookup and becomes a *companion that remembers you*.
- **Unlocks:** the first real reason to pay (personalization + alerts).
- **Metric that matters:** % of users who set at least one watchlist/alert.

## Phase 3 — Coach / advisor dashboard
**Features:** multi-user management, client notes, career plans, role recommendations.
- First clear **B2B** wedge: career coaches, bootcamps, advisors managing many clients.
- **Unlocks:** seat-based pricing; higher willingness to pay than B2C.
- **Metric that matters:** clients managed per coach.

## Phase 4 — Institution / workforce product
**Features:** school dashboards, employment centres, workforce programs, cohort analytics.
- Sells to organizations with a mandate and a budget (colleges, WorkBC-style centres, workforce boards).
- **Unlocks:** contract revenue, cohort-level labour-market reporting.
- **Metric that matters:** cohorts onboarded; outcomes tracked.

## Phase 5 — Market expansion
**Features:** other Canadian cities, U.S. metros, industry-specific dashboards.
- The whole system is already **market-configurable** (one config file retargets the pipeline + UI).
- **Unlocks:** TAM expansion without rebuilding the engine.
- **Metric that matters:** markets live; incremental cost per new market (should trend to near-zero).

## Phase 6 — Data / API layer
**Features:** API endpoints, embeddable widgets, B2B labour-market intelligence reports.
- The dashboard was always the wedge. **The clean, grounded data layer is the moat.**
- **Unlocks:** the highest-margin line — sell the intelligence, not just the interface.
- **Metric that matters:** API revenue / integrations.

## The value ladder in one view
| Phase | Who pays | For what | Moat |
|-------|----------|----------|------|
| 0 Proof-of-work | (nobody) | credibility | the system design itself |
| 1 Gated beta | (nobody yet) | access | user base forming |
| 2 Personal layer | individuals | memory + alerts | personalization data |
| 3 Coach dashboard | coaches/bootcamps | manage clients | workflow lock-in |
| 4 Institution | schools/gov | cohort outcomes | contracts + integration |
| 5 Expansion | all of the above | more markets | config-driven scale |
| 6 API/data | businesses | grounded intelligence | the data layer |

## What I'd say publicly about it
"I'm not claiming this is a scaled product. It's Phase 0. But I designed Phases 1–6 before
I shipped Phase 0 — because the point was never the dashboard. The point was proving I can see
the whole ramp: from research, to system, to product, to business."
