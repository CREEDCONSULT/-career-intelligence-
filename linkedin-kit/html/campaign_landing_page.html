Context · Why I built it

I don't only use AI. I build systems with AI.

I stopped treating AI as something I only ask questions. I started treating it as infrastructure. Careers were the perfect test case — a decision-heavy problem, drowning in generic advice, sitting on top of real public data almost nobody uses well. So I took that architecture apart and rebuilt it as a system: data first, AI second, UX third.

Product thesis

Career advice should not just sound intelligent. It should be grounded.
The model is not the source of truth. The system is.

System architecture

Six layers. One rule.

Data→Analytics→ AI Guardrails→UX →Evaluation→Productization
01

Data

Job Bank, Statistics Canada, Indeed Hiring Lab, Lightcast, NOC 2021 — five official sources, one clean queryable store.

02

Analytics

Raw signals become skills in demand, salary ranges, role demand, and hiring trends.

03

AI · guarded

Explains, summarizes, guides — writes validated SQL and narrates only real results. Never invents a number.

04

UX

Eight focused modules make the system usable. Every answer shows its work.

05

Evaluation

Trust is measured: execution accuracy, faithfulness, refusal behaviour — with real numbers.

06

Productization

A phased path from open demo to a B2B labour-market intelligence layer.
